# Form-Styling
A practice project focused on styling HTML forms with CSS, including input fields, buttons, labels, validation states and responsive layouts.
# Form Styling

## About This Project

This project is part of my software and web development course. I'm using it to practise styling HTML forms with CSS and learn how to make them look cleaner, more organised and easier to use.

I'll be experimenting with different form elements, layouts and styles to see how small design changes can improve the overall user experience.

## What I'm Working On

- **Input fields** – styling text fields, email fields and password inputs.
- **Labels and placeholders** – making form fields clear and easy to understand.
- **Buttons** – creating custom submit buttons with hover effects.
- **Focus states** – changing the appearance of fields when they're selected.
- **Form validation styling** – experimenting with how valid and invalid inputs can be displayed.
- **Layout and spacing** – using CSS to organise form elements and keep everything consistent.
- **Responsive design** – making the form work on different screen sizes.

## Technologies Used

- HTML5
- CSS3

## What I've Learned

This project gives me the opportunity to practise using CSS to style different form elements and understand how layout, spacing, colours and interactive states affect usability.

I'll keep experimenting with different styles as I work through the project and improve my understanding of form design.

## How to View the Project

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Try out the form and explore the different styling and interaction states.
